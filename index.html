How to Play

Drop falling pieces like Tetris. Every block has a colour.

Match 3 or more same-coloured gems in a row or column and they pop, like Candy Crush. Gems above fall down and can start chain reactions.

Fill a whole row to clear it too, for a big bonus.

Solve the 50-level Puzzle Campaign. Each level has a goal, a minimum score and a limited number of pieces. Higher levels give bigger goals and the pieces fall faster as you climb the ranks.

Earn gem coins every time you clear a level (more stars = more coins). Spend them in the Shop on 50 block styles, 50 UI themes, 50 UI sound packs and 50 music tracks. Every 5 levels you clear unlocks 5 more items in each category.

Controls: ← → move · ↑ / X rotate · ↓ soft drop · Space hard drop · P / Esc pause. On touch screens use the buttons below the board.

Your game saves automatically, so you can close the tab any time and choose Continue later.
